# 🍳 냉장고 레시피 추천 시스템 (Recipe Recommender)

## 📖 프로젝트 개요
"냉장고 레시피 추천 시스템"은 사용자의 냉장고 속에 남아있는 재료들을 입력받아 최적의 요리 레시피를 추천해주는 파이썬 기반의 CLI(Command Line Interface) 프로그램입니다.

단순히 재료의 보유 여부만 확인하는 것을 넘어, **유통기한 임박 정도**, **재료 소모량**, **레시피 매칭률**을 종합적으로 스코어링하여 현실적이고 경제적인 식사 메뉴를 제안합니다.

---

## ✨ 주요 기능 및 특징
* **스마트 가중치 알고리즘 (`RecipeScorer`)**: 
    * 🕒 **유통기한 (50%)**: D-Day 7일 이내의 임박한 재료가 포함된 레시피에 가장 높은 가중치 부여.
    * ⚖️ **재료 소모량 (30%)**: 보유한 재료를 가장 많이 소모할 수 있는 레시피 우대.
    * 🎯 **매칭률 (20%)**: 레시피에서 요구하는 핵심 재료와 사용자의 보유 재료 일치 비율 계산.
* **유통기한 자동 계산 및 정렬**: 입력된 날짜(YYYY-MM-DD)를 바탕으로 현재 날짜 기준의 D-Day를 계산하고 임박순으로 데이터를 정렬합니다.
* **Numpy 기반 벡터 연산**: 사용자의 재료 수량을 비율 벡터로 변환하여 분석합니다.
* **직관적인 UI**: 콘솔 화면 초기화 및 깔끔한 텍스트 기반 인터페이스 제공.

## 🚀 사용 방법 및 예시 (Usage)
프로그램을 실행하면 터미널에서 1~4번의 메뉴를 선택하여 상호작용할 수 있습니다.

1. 메뉴 선택 및 재료 입력
메인 메뉴에서 1번을 선택하고 화면의 안내에 따라 냉장고에 있는 재료를 입력합니다.

```Plaintext
>> 원하는 메뉴 번호를 선택하세요: 1

[새 재료 추가]
1. 재료 이름 (예: 김치, 계란): 돼지고기
2. 양 (예: 500g 등 gram 단위 기준으로 정확히 입력해 주세요): 600
3. 유통기한 (YYYY-MM-DD 형식, 예: 2026-05-30): 2026-06-15

✅ [돼지고기] 등록 완료! (계속 추가하려면 다음 재료를 입력하세요)
```
2. 맞춤 레시피 추천 결과 확인
입력을 마친 후 메인 화면에서 3번(맞춤 레시피 추천받기) 메뉴를 선택하면, 내부 로직에 따른 재료 비율 분석 및 추천 요리 TOP 3가 출력됩니다.
```Plaintext
>> 원하는 메뉴 번호를 선택하세요: 3

[레시피 추천 결과]

==== 입력 기반 재료 비율 분석 ====
- 김치: 40.0%
- 돼지고기: 60.0%

==== 맞춤 레시피 추천 TOP 3 ====
1위: 김치찌개 (가중치 점수: 0.85)
2위: 제육볶음 (가중치 점수: 0.72)
3위: 김치볶음밥 (가중치 점수: 0.61)
```
## 🛠️ 내부 구조 (Architecture)
INGREDIENTS & RAW_RECIPES: 기준 재료 리스트 및 레시피 데이터베이스 딕셔너리

process_ingredients(): 입력받은 Raw 데이터를 정제하고 유통기한(D-Day)이 임박한 순으로 정렬하는 핵심 데이터 파이프라인

RecipeScorer: 객체 지향적으로 설계된 클래스로, 가중치 로직을 통해 각 레시피의 적합도 총점을 계산

RecipeRecommenderCLI: 콘솔 창 제어(os.system) 및 사용자와의 직접적인 상호작용(입출력) 담당

## 🧪 테스트 방법
알고리즘이 정상 작동하는지 확인하려면 아래의 시나리오대로 테스트해 보세요.

1. 프로그램 실행 후 초기 메뉴에서 1을 눌러 스파게티면(수량: 200, 기한 없음), 토마토소스(수량: 300, 2026-12-31)를 차례대로 추가합니다.

2. 3번 메뉴를 눌러 추천 결과를 확인하고, 토마토파스타가 1위로 출력되는지 검증합니다.

3. 다시 1번 메뉴로 들어가 두부를 추가하고 유통기한을 '오늘 날짜로부터 3일 뒤'로 짧게 설정해 봅니다.

4. 다시 추천을 받았을 때, 유통기한 가중치가 적용되어 된장찌개나 김치찌개의 순위가 급격히 상승하는지 확인합니다.
